# TinyMDEdit

Un éditeur Markdown **natif** et *volontairement simple* pour macOS.

## Ce que ça fait

Le texte que vous lisez est le fichier `.md` lui-même : les marqueurs restent là,
ils sont juste affichés en gris discret. Vous pouvez taper dedans normalement.

### Deux modes

- **Mise en page** — les titres sont gros, le gras est gras
- **Texte brut** — tout en monospace, aucune coloration
- Bascule avec le sélecteur en haut, ou avec ⇧⌘M

### Le reste de la syntaxe

1. Les listes numérotées sont indentées proprement
2. Le `code en ligne` ressort sur fond coloré
3. Les [liens](https://example.com) aussi
4. Et le ~~texte barré~~ également

> Les citations passent en italique, décalées vers la droite.

- [x] Une case à cocher
- [x] Une case cochée

